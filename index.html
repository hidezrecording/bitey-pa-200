01 · The machine

Broadcast bones.
Studio attitude.

A fast, character-first mixer built around tube-driven spring reverb and three-speed tape slap. Push it for harmonic bite and unruly low-end movement, or pull it back for a small, convincing room that sits behind the source.

Two input strips

Level, pad, 96 Hz cut, musical EQ and independent reverb sends.

Three tape speeds

7.5, 15 and 30 IPS shift the timing, weight and color of the slap.

Tube spring

Drive, contour, time and level shape a spring that can glow or snarl.

macOS installation

Download the latest Mac installer, then follow these steps if Gatekeeper or your DAW blocks Bitey.

Download Mac installer ↗
  1. Run the installer. Download and open the .pkg file.
  2. Approve it in Gatekeeper if macOS blocks it. Go to System Settings → Privacy & Security, scroll down, then click “Open Anyway.”
  3. Clear quarantine if your DAW still refuses the plug-in. Open Terminal and run the AU command below. For VST3, use the second command.xattr -cr ~/Library/Audio/Plug-Ins/Components/Bitey.componentxattr -cr ~/Library/Audio/Plug-Ins/VST3/Bitey.vst3
  4. Rescan plug-ins in your DAW, then load Bitey as an AU or VST3.
